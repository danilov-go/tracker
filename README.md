# Activity Tracker Engine

Библиотека на Go для парсинга и расчета показателей физической активности (бег, ходьба). 

### ✨ Ключевые особенности:
*   **Интерфейсы:** Использование `DataParser` для гибкой обработки различных типов данных.
*   **Композиция:** Эффективное использование встраивания структур (Embedding) для работы с персональными данными.
*   **Валидация:** Строгая проверка входящих данных (защита от отрицательных значений шагов, веса и времени).
*   **Пакетная архитектура:** Четкое разделение ответственности между расчетом энергии, парсингом и хранением данных.

### 🛠 Стек:
Go (Standard Library: strings, strconv, time, errors, fmt, log).

### 🚀 Запуск демонстрации:
```bash
go run ./cmd/tracker/main.go
```

### 🧪 Тестирование:
Для запуска всех тестов в проекте выполните:
```bash
go test ./...
```

### 📋 Пример входных данных:
Программа поддерживает обработку данных в форматах:
- Дневная активность: `"шаги,длительность"` (напр. `"1000,1h30m"`)
- Тренировки: `"шаги,тип,длительность"` (напр. `"5000,Бег,0h45m"`)
